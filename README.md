# Godot BBMODEL Importer: Support

Help, documentation and issue tracking for the **Godot BBMODEL Importer**, a Godot 4 editor plugin that imports
Blockbench `.bbmodel` files directly as scenes (no glTF export step).

> The importer is a free, MIT-licensed addon by Djagdev.
> Download: [itch.io page](https://djagdev.itch.io/blockbench-bbmodel-importer-for-godot-4). Quick questions: use the comments there.

* [Known issues and limits](docs/KNOWN-ISSUES.md)
