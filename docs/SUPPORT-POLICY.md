# Support policy

* Bug reports, feature requests and compatibility reports: open an issue with the matching template.
* Response time is best-effort; there is no guaranteed turnaround.
* Please do not post files you do not have the right to share. A minimal `.bbmodel` you made yourself is ideal.
* Feature requests are welcome but are not promises.
* Updates for the same major version are free.
* Security issues or anything private: do not post publicly; contact the maintainer through the page where you got the plugin.
